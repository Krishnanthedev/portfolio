# 🚀 3D Dynamic Developer & Designer Portfolio

A sleek, modern, interactive single-page portfolio featuring dynamic 3D elements, glassmorphism UI components, vibrant gradient typography, and an interactive floating navigation dock. Built for high performance, smooth responsiveness, and seamless user interaction.

## ✨ Key Features

* **Dynamic 3D Hero Scene:** Smooth-floating, interactive 3D geometry (spheres/toruses) powered by Three.js/React Three Fiber that reacts to cursor movements and parallax scrolling.
* **Gradient Typography:** Eye-catching linear gradients (*Deep Cyan to Electric Indigo*) applied to primary headers and brand identity.
* **Glassmorphism UI:** Translucent card layouts with subtle dark overlays (`bg-slate-900/50`), thin borders, and backdrop blur effects (`backdrop-blur-md`).
* **Floating Icon Dock Navigation:** Fixed bottom glassmorphism navbar featuring icon-only navigation with animated tooltip badges on hover.
* **Interactive Sections:**
  * **Hero:** High-impact gradient headline, interactive 3D background object, and a **'Download Resume'** button with hover animations.
  * **Skills:** Categorized technical skill cards with micro-hover animations.
  * **Projects:** Grid showcase featuring project descriptions, tech stack tags, and direct **'Live Demo'** external buttons.
  * **Education:** Minimalist timeline displaying academic background and degrees.
  * **Certifications:** Interactive credential grid complete with direct online verification hyperlinks.
  * **Get in Touch:** Centered boxed contact form with glowing gradient input focus states (Name, Email, Message).

## 🛠️ Tech Stack

* **Frontend Framework:** [React.js](https://react.dev/) / [Vite](https://vitejs.dev/)
* **Styling & UI:** [Tailwind CSS](https://tailwindcss.com/)
* **3D Graphics & Animations:** [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) / [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Deployment:** Vercel / GitHub Pages
